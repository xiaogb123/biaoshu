**卡在哪**：`documents.py` 踩了 6 个坑，两个值得记：

1. 代码写出了 `try` 块外（缩进回到 4 格），`finally` 找不到配对的 `try`，报
   `SyntaxError: expected 'except' or 'finally' block`。**这已经是第二次犯**——
   Python 报错指向的行是"撞墙处"，真正的错在它的上一行或更浅的缩进。
2. 用了 `Tenant.id`（类属性）而不是 `tenant.id`（注入的实例）。不报错，
   但去重查询比较的是"列 = 列"，永远匹配不到，每次上传都新建。
   静默错误比报错危险得多。

**今天学到**：

- `pymupdf` 的 `insert_image(pixmap=pix)` 存的是无损图，10 页就能超 50MB，
  必须走 `pix.tobytes("jpeg", jpg_quality=70)` + `save(deflate=True)`
- PowerShell 5.1 里 `curl` 是 `Invoke-WebRequest` 的别名，不认 `-F`，必须写 `curl.exe`
- `python -m scripts.xxx` 和 `python scripts\xxx.py` 的 `sys.path` 不一样，前者才找得到 `app` 包
