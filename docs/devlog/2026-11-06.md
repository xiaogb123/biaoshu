**今天学到**：

- `temperature=0` 不等于确定性。同一份文件跑 4 次，条数 157 / 160 / 178 / 198，
  波动 26%；分类分布也跟着变（scoring 在 21~32 之间跳）。
  **验收一律用比率，不用条数**——条数受采样波动支配，比率才反映机制有没有问题。
- "严格逐字命中 59%" 是假警报。逐条 diff 后发现 40% 的 failure 是
  **模型把 PDF 的版式折行抹平了**（`并视\n情况` → `并视情况`），一个字都没改。
  这也是第 5 天归一化必须做 NFKC + 去空白的实证依据，不能只靠"感觉"。
- 换行差异细分：原文有换行 / quote 没有 = 75 条；两边都有换行但位置不同 = 5 条；
  真正改字符 = 1 条（评分表里「、」写成「，」，表格页已知弱项，留给 pdfplumber）。
- 空批不能直接当失败。3 个 0 条批次查了原文，全是服务合同正文、
  电子卷宗加工规范、中小企业划型标准——按规则 3「没有条款就返回空数组」，
  返回空**才是对的**，吐出一堆才是编。
- 页码准确率靠的是 `<PAGE n>` 标记。两次全量校验都是 0 条偏差，
  证明这个显式分隔符机制有效，规则 2 不需要加补丁。

**数据**：全量 115 页 15 批 → 157~198 条（4 次跑的波动范围），62~70s，0 批失败；
